EuroAPPA Prototype P4: Checklist Generator

2026-05-28 by Jorrit Poelen

This page dynamically generates an insect pollinator checklist for a specific NUTS region. This checklist is made available as a downloadable csv file using in-browser DuckDB database queries and a remote EuroAPPA parquet file. So, no server side database needed, just a place to put a single parquet file for download (e.g., euroappa-nuts-2021-col.parquet). This prototype demonstrates that checklists can be dynamically generated with minimal infrastructure (e.g., no remote database server like mysql/mariadb needed) and commonly used technology (e.g., HTML, JavaScript, and SQL) and EuroAPPA data products provided via Prototype P3.

methods

On loading this webpage, the browser installs (1) DuckDB as a WebAssembly module. Following, the webpage instructs the browser to send a SQL query to the DuckDB module (2) to compile a checklist. This query is executed by DuckDB (3) using a remote parquet file (4) containing a EuroAPPA data product prototype in the parquet format. The DuckDB module now returns the CSV file to the browser. Following, the generated checklist is made available as a CSV file (5). All this, using this single webpage containing HTML, JavaScript and a single parquet data file available for download.
